# Website CV — Đỗ Đăng Tuân

CV/portfolio cá nhân dạng một trang, giới thiệu hồ sơ, kinh nghiệm và các dự án
của Đỗ Đăng Tuân — Fullstack Developer.

## Giới thiệu

Website tổng hợp những thông tin chính trong CV:

- Hơn 2 năm kinh nghiệm frontend với Vue 3, TypeScript và React.
- 6 tháng làm backend với .NET Core, PostgreSQL và Doris.
- Kinh nghiệm lead frontend cho hệ thống ERP nội bộ GPlay Hub.
- Các dự án tiêu biểu trong lĩnh vực web app, landing page và browser extension.
- Học vấn, chứng chỉ, giải thưởng và hoạt động cộng đồng.
- Bản CV PDF có thể tải trực tiếp từ website.

Nội dung được trình bày ngắn gọn, tập trung vào kết quả công việc và liên kết tới
các sản phẩm đang hoạt động thật.

## Phiên bản thiết kế

Website lưu nhiều phiên bản giao diện để thuận tiện so sánh và quay lại thiết kế cũ:

- **v1.1.0 — "Signal"**: phong cách neo-brutalist, nền sáng, viền đen, điểm nhấn
  cam và xanh acid.
- **v1.0.0**: giao diện editorial ấm, tối giản với màu be, xanh và xanh lime.

Các phiên bản dùng chung nội dung, hình ảnh, font và CV PDF.

## Công nghệ

HTML, CSS và JavaScript thuần, không dùng framework hay bước build. Giao diện
responsive, hỗ trợ điều hướng bàn phím và tôn trọng thiết lập giảm chuyển động.
Font Fraunces, Be Vietnam Pro và IBM Plex Mono được self-host.
